# TypeFire

**A text expander, a clipboard manager and a Markdown notebook, in one Mac app.**
Download it at **[typefire.app](https://typefire.app)**.

Three keyboard shortcuts reach all three from inside whatever you are working in, so you never switch windows to get to any of it.

## What it does

- **Snippets.** Type three characters, get the whole thing. Any block of text gets an abbreviation that expands in every Mac app and every website.
- **Clips.** Your clipboard history, kept and searchable, including the words inside your screenshots.
- **Notes.** A real Markdown editor: live rendering, wikilinks and backlinks, daily notes, nested tags. It writes plain `.md` files, so it opens a folder of Markdown or an existing vault where it sits.

Everything is stored as plain files on your own disk. Nothing is uploaded, and there is no account required to use it.

## Install

Download the latest `.dmg` from [Releases](https://github.com/navbuildz/typefire-builds/releases/latest), or from [typefire.app](https://typefire.app).

Apple Silicon Macs, macOS 12 or later. Signed and notarised.

## Free, and what Pro adds

Text expansion, Markdown notes and recent clipboard history are **free** and are not a trial.

Pro is **$18 once**, never a subscription, and adds full clipboard history, screenshot text search, iCloud sync across your Macs, AI Selection Prompts and Prompt Chains.
